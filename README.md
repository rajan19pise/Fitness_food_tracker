# Fitness & Diet Tracker

A simple Flask-based fitness and nutrition tracking application.

## Features
- Add meals
- Track calories
- Track protein, carbs, and fats
- View daily totals
- Meal history table

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Installation

```bash
pip install flask
```

## Run Project

```bash
python app.py
```

Open:
http://127.0.0.1:5000

Requirements: 
Flask 3.0.3
